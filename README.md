# Лидер интерьера — мебельная студия

React + Vite + Tailwind CSS v4.

## Запуск

```bash
npm install
npm run dev
```

## Переменные окружения

Создайте `.env.local`:

```
VITE_TG_BOT_TOKEN=ваш_токен
VITE_TG_CHAT_ID=-5494462395
```

## Сборка

```bash
npm run build
# Готовые файлы в dist/
```

## Примечание

Бинарные ассеты (фото команды, hero-фото) хранятся локально в `src/assets/` и не включены в этот коммит из-за ограничений среды. Добавьте их вручную при клонировании.
